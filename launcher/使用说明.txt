画布工作台 · Windows 便携整合包

1. 将整个 ZIP 解压到机械盘，例如 D:\CanvasStudio。不要只拖出 EXE，不要在压缩软件内直接运行。
2. 双击“画布工作台启动器.exe”。无需安装 Node、Go 或 Docker，无需软件账号或密码。
3. 打开“模型配置”，可新增多个 OpenAI 兼容渠道，分别填写接口与 API Key。测试连接后选择需要的模型并指定文字、图片或视频类型，也可手动填写模型名称。再为白模、文字、图片和视频分别选择“渠道 · 模型”，点击“保存全部配置”。白模导演使用支持工具调用的文字模型，参考图需要视觉输入。
4. 点击“一键启动工作台”。在首页选择 Edge、Chrome、Firefox，或点击“选择浏览器程序”指定主程序；启动和打开时自动保存此选择。
5. 画布内添加导演台节点，打开后即可使用 CozyClay。底部工具栏可以保存场景、截图到画布、动画到画布；按 Ctrl+B 打开 AI 面板。

数据位置：默认位于整合包内 data 文件夹。数据库、素材、导演台项目、生成记录、输出、日志、临时文件与专用浏览器资料均位于其中。
导出下载默认写入 data\outputs。保存场景成功后才会显示“已保存到本机”。
本地编辑无需联网；在线模型生成需要网络及服务商额度。动作基于 CozyClay 当前已有骨骼和动作编译能力，复杂动作可能需要调整。
API Key 通过 Windows 加密保存。移动到另一台电脑或 Windows 用户后，请重新输入密钥。不要将自己的 data 文件夹作为发行包发给别人。
各渠道密钥分别保存，留空保留该渠道原密钥，清除一个渠道不影响其他渠道。相同模型名称可配置在多个渠道，使用时会按所选渠道调用。
停用、删除渠道或移除模型后，相关默认选择会清空，请重新选择。已提交视频任务仍使用原渠道查询，不会因切换默认渠道而重复提交。查询尚未结束前请保留原渠道及其模型。
画布的模型下拉列表可以切换渠道；白模导演的 AI 面板可直接选择“渠道 · 模型”。在启动器修改配置后刷新工作台，已打开的导演台请关闭再打开。
“切换数据目录”会切换工作区，原目录文件保留；若要继续已有工作，请选择已有 data 文件夹。操作前关闭工作台浏览器并停止服务。
关闭浏览器不停止服务，退出启动器才停止服务。退出前等待保存完成。程序更新保留 data 和 portable.json。在“检查与修复”中可检查 GitHub 在线更新、下载并校验后重启安装，也可导入完整的本软件发行 ZIP。已下载并校验的更新在关闭后可以恢复；检查失败不影响已有工作区。

故障处理：在“运行日志”查看具体错误；机械盘不可用时恢复该盘后重启，不会自动切换系统盘。接口测试不发起收费生成任务。

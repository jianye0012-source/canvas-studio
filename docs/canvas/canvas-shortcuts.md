# 画布快捷键

本文档记录画布里常用的鼠标和键盘操作。

## 视图

- 拖动画布空白处：框选节点。
- 按住 `Space` 拖动：临时反转选择/移动工具（选择工具时临时平移，移动工具时临时选择）。
- 鼠标中键拖动：平移画布。
- 鼠标滚轮：缩放画布。
- `Ctrl / Cmd` + 滚轮：缩放画布。
- 缩放滑杆：精确调整缩放。
- 重置视图按钮：回到默认缩放和居中位置。

## 选择

- 拖动画布空白处：框选多个节点。
- `Shift` + 拖动空白处：追加框选。
- `Shift / Ctrl / Cmd` + 点击节点：追加或取消选择节点。
- `Ctrl / Cmd` + `A`：全选画布节点。
- `Esc`：取消选择，并关闭当前浮层。

## 编辑

- `Ctrl / Cmd` + `C`：复制选中节点。
- `Ctrl / Cmd` + `V`：粘贴节点；如果剪贴板有文本或图片，也会粘贴为对应节点。
- `Ctrl / Cmd` + `G`：把选中的节点创建为组。
- `Delete / Backspace`：删除选中的节点或连线。
- `Ctrl / Cmd` + `Z`：撤销。
- `Ctrl / Cmd` + `Shift` + `Z`：重做。
- `Ctrl / Cmd` + `Y`：重做。

## 图片和素材

- 拖入图片文件：上传图片到画布。
- 拖入视频文件：上传视频到画布。
- 拖入音频文件：上传音频到画布。
- 导入图片按钮：从本地选择图片。
- 素材库或我的素材：选择素材后插入画布。

## 撤销和重做范围

撤销和重做会记录画布节点、连线、背景模式和图片信息显示状态。画布视口、助手会话、画布项目名称、账号状态、全局 AI 配置和“我的素材”保存操作不属于当前画布历史。

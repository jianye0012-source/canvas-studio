# 待测试

## v1.3.2 新增验收

- 导演台 H.264 视频附件由本机 FFmpeg 抽取九宫格画面，不再依赖浏览器解码器；视频仅在发送消息时作为抽帧图交给视觉模型，支持 1 GB 以内视频。损坏视频提示原因，处理结束清理临时文件。
- 导演台 MCP 已验证放置白模道具、读取场景和导出本机项目文件；文件保存限定数据目录，越界路径被拒绝。
- 小尺寸循环节点可在内部滚动查看错误和重试操作，不会把文字压缩隐藏。
- FOR 文件夹循环通过启动器原生对话框选目录，支持子目录与自然文件名排序；逐文件执行相连工作流，每步一份结果。支持文本、图片、视频、音频、全景、生成配置；首版不嵌套循环，不自动操作导演台或组。
- 循环保存输入快照、模板、步骤和结果，暂停时等待当前任务完成。重新打开后手动继续，已有服务器任务只查询，不自动重发；提交状态未确认时停止并要求用户核对后重试。输入文件变动或路径失效会停止。
- 画布 MCP `canvas-studio-canvas` 与导演台 MCP `canvas-studio-director` 随包运行，支持 stdio 与 Streamable HTTP；多个工作区须明确指定。MCP 面板提供独立配置，导演台底部提供专属配置入口，无需原项目插件或 Codex CLI。
- 启动器 Skill 管理支持新建、编辑、Markdown／文本导入、导出和删除，存储在本机数据库；文字节点和文字生成配置可选择最多五个 Skill。MCP 支持管理用户 Skill、选择渠道和 Skill 生成 AI 文字。
- 已通过 15 项启动器单元测试、原生 Electron Skill 管理与重启测试、通用 MCP HTTP＋stdio 测试、两个文件各执行两步及暂停刷新恢复、Skill 请求注入、H.264 8 位 420／10 位 444 样例及实际附件 UI 测试。原导演台场景、模型、动作、截图／MP4 回传和新浏览器恢复回归通过。
- 仍需在 Windows 实机确认原生目录选择、H.264 原始问题文件、不同外部 MCP 客户端的配置界面和真实模型 API。没有收到用户原始视频，本次使用编码样例验证。

## Windows 本地工作台整合版

- 首页指定 Edge、Chrome、Firefox 或自选浏览器程序，启动与打开时自动保存，重启保留；不同自选程序使用独立资料目录。
- GitHub Releases 更新框架：启动时或手动检查、下载进度、SHA-256 与文件清单校验、重启恢复待安装包、安装前再校验；保留离线导入。配套公开源码与 Windows 构建发布工作流。
- 中文启动器：一键启动／停止、模型配置、存储设置、日志、检查、发行包导入和关于。
- 固定本机身份，无账号登录；项目和任务通过本地 SQLite 保存，素材写入数据目录。
- 启动器和浏览器共用模型配置；系统加密保护 API Key，浏览器通过本机代理调用。
- 支持多个独立渠道，分别测试连接、管理模型和加密密钥；白模、文字、图片、视频可分别指定默认渠道及模型，画布与导演台内也能切换。同名模型按渠道区分，已有视频任务仍从原渠道查询，保留上一版单渠道设置。
- CozyClay 替换导演台，完整项目文件保存导入资产，截图和动画回传画布并加入素材库。
- 移除滚动营销、推广入口、主界面 GitHub 图标和版本号；许可与对应源码保留。
- 已做 Linux 构建、后端和启动器测试及浏览器联调；Windows 实机、DPAPI、真实 AI 服务和更新应用流程尚待验收。

构建与测试说明见 [Windows 整合包](../desktop-build.md)。
